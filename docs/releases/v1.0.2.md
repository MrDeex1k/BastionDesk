# BastionDesk v1.0.2

A maintenance release focused on modernizing developer tooling, making dependency resolution
more predictable, and refreshing the base container images used by the supported Docker Compose
deployment.

BastionDesk `1.0.2` does not change the functional scope of the `1.0.x` line. The update
standardizes TypeScript linting, formatting, and compilation, pins exact package versions, and
updates selected runtime images without an intended change to the API, database schema, or
user-facing application behavior.

## Developer Tooling

- Migrated the frontend from ESLint to type-aware OxLint.
- Migrated backend checks from Biome to type-aware OxLint.
- Standardized OxFmt as the TypeScript and TSX formatter, with separate configuration for the
  frontend and backend.
- Updated the frontend and backend to TypeScript `7.0.2`.
- Changed the frontend ECMAScript target and libraries from `ES2025` to `ESNext`.
- Normalized existing TypeScript and TSX sources according to the OxFmt configuration.
- Updated the README to identify Oxc as the current linting and formatting toolchain.

## Dependencies

- Updated frontend and backend dependencies and their Bun lockfiles.
- Pinned every direct version in the Bun manifests exactly, without `^` or `~` ranges.
- Reduced the Bun release-age quarantine from 60 to 48 hours (`172800` seconds).
- Kept the same 48-hour quarantine in dependency installation and update scripts.
- Updated the Python dependencies of `llm_service` and regenerated `uv.lock`.
- Pinned direct dependencies in `llm_service/pyproject.toml` with `==`: FastAPI `0.139.0`, gRPC
  and gRPC Tools `1.82.1`, Hugging Face Hub `1.23.0`, PyTorch `2.13.0`, Transformers `5.13.1`,
  and Uvicorn `0.51.0`.
- Reduced the `uv` release-age quarantine from 60 to 48 hours, matching the Bun policy.

## Container Images

- Updated the public reverse proxy and frontend container from `nginx:1.31.1-alpine` to
  `nginx:1.31.2-alpine3.23`.
- Updated PgBouncer from `edoburu/pgbouncer:v1.25.1-p0` to
  `edoburu/pgbouncer:v1.25.2-p0`.
- Updated the PgBouncer and storage helper stages from `busybox:1.37.0-musl` to
  `busybox:1.38.0-musl`.
- Updated the `llm_service` builder and runtime from
  `ghcr.io/astral-sh/uv:0.11.7-python3.13-trixie-slim` to
  `ghcr.io/astral-sh/uv:0.11.28-python3.13-trixie-slim`.

## Deployment Notes

- The supported `1.0.2` release model remains self-hosted Docker Compose.
- The deployment model remains `fresh install only`.
- The main public entry point remains `http://localhost:4567`.
- The update does not intentionally change environment configuration, the API, or the database
  schema.
- Because base images changed, a complete Docker Compose build and smoke test should be performed
  before publication.

Main deployment documentation:

- [Deployment Guide](../infrastructure/deploy.md)

## Known Notes

- `1.0.2` remains a maintenance release in the `1.0.x` line.
- The release does not introduce a new public binary artifact or an image published to an
  external registry.
- Release source archives are derived from the `v1.0.2` Git tag created after the changes are
  merged and validated.
