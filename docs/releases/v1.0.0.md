# BastionDesk v1.0.0

The first public release of BastionDesk.

BastionDesk is a self-hosted cybersecurity incident management platform built for organizations
that need a structured incident reporting, classification, and handling process without the
overhead of large enterprise systems. Version `1.0.0` delivers a complete product foundation:
frontend, backend, roles and organizations, incident workflows, file storage, a local LLM
module, backups, and a supported Docker Compose deployment.

## Included

- Self-hosted Docker Compose deployment for the complete BastionDesk stack.
- Better Auth-based authentication with email/password, cookie sessions, passkeys/WebAuthn,
  organizations, and the `pracownik`, `analityk`, and `admin` roles.
- Employee incident reporting workflow with descriptions, screenshots, and attachments.
- Analyst workflow covering incident assignment, notes, statuses, reports, and final statements.
- Administration views for managing organizations, members, and incident analytics.
- Local LLM service based on `google/gemma-3-1b-it`, classifying incidents as `Czerwony`,
  `Żółty`, or `Zielony`.
- S3-compatible distributed MinIO storage with automatic bucket bootstrap and versioning.
- Automated PostgreSQL backups to MinIO with retention and verified restore support.
- Reverse proxy exposing the main application entry point at `http://localhost:4567`.
- Standardized runtime stack: Bun, React 19, Vite 8, Express 5, PostgreSQL, PgBouncer, MinIO,
  FastAPI, and gRPC/mTLS.

## Security

- Community Edition released under the `AGPL-3.0-only` license.
- TLS or mTLS for PostgreSQL, PgBouncer, backend-to-LLM, and backend-to-MinIO communication.
- Helmet, CORS allowlisting, rate limiting, and Zod input validation.
- Non-root runtime for the main application containers.
- Dependency age gates for Bun and `uv` to reduce exposure to newly introduced supply-chain
  regressions.

## Known Limitations

- `1.0.0` does not provide an official in-place upgrade path from earlier installations.
- The officially documented deployment path covers Docker Compose, not a full matrix of other
  orchestrators.
- `llm_service` has noticeable memory requirements and may have a cold start while loading the
  model.
- The local certificate generator under `infra/tls/` is intended for development and should be
  replaced with production PKI in production environments.
