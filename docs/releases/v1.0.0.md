# BastionDesk v1.0.0

Pierwsze publiczne wydanie BastionDesk.

BastionDesk to self-hosted platforma do obsługi incydentów cyberbezpieczeństwa, zbudowana z myślą o organizacjach, które potrzebują uporządkowanego procesu zgłaszania, klasyfikacji i obsługi incydentów bez ciężaru dużych systemów enterprise. Wersja `1.0.0` dostarcza kompletną bazę produktu: frontend, backend, role i organizacje, workflow incydentów, storage plików, lokalny moduł LLM, backupy oraz wspierany deployment przez Docker Compose.

## Included

- Self-hosted Docker Compose deployment dla pełnego stacka BastionDesk.
- Uwierzytelnianie oparte o Better Auth: email/password, sesje cookies, passkeys/WebAuthn, organizacje i role `pracownik`, `analityk`, `admin`.
- Workflow zgłaszania incydentów przez pracownika z obsługą opisu, screenshotów i załączników.
- Workflow analityka: przypisanie incydentu, notatki, statusy, raport i końcowe sprawozdanie.
- Widoki administracyjne do zarządzania organizacją, członkami i analityką incydentów.
- Lokalny serwis LLM oparty o `google/gemma-3-1b-it`, klasyfikujący incydenty do kategorii `Czerwony`, `Żółty`, `Zielony`.
- S3-compatible storage na distributed MinIO z automatycznym bootstrapem bucketa i włączonym versioningiem.
- Automatyczne backupy PostgreSQL do MinIO z retencją i zweryfikowanym restore.
- Reverse proxy z głównym punktem wejścia aplikacji pod `http://localhost:4567`.
- Uporządkowany stack runtime: Bun, React 19, Vite 8, Express 5, PostgreSQL, PgBouncer, MinIO, FastAPI i gRPC/mTLS.

## Security

- Community Edition wydany na licencji `AGPL-3.0-only`.
- TLS lub mTLS dla komunikacji PostgreSQL, PgBouncer, backend -> LLM i backend -> MinIO.
- Helmet, CORS allowlisting, rate limiting i walidacja wejścia przez Zod.
- Non-root runtime dla głównych kontenerów aplikacyjnych.
- Polityka age-gate dla zależności Bun i `uv`, aby ograniczyć ryzyko świeżych regresji supply-chain.

## Known Limitations

- `1.0.0` nie dostarcza oficjalnej ścieżki upgrade in-place ze starszych instalacji.
- Oficjalnie opisana ścieżka deploymentu obejmuje Docker Compose, nie pełny matrix innych orkiestratorów.
- `llm_service` ma zauważalne wymagania pamięciowe i może mieć cold start podczas ładowania modelu.
- Lokalny generator certyfikatów w `infra/tls/` jest przeznaczony dla developmentu i powinien zostać zastąpiony własnym PKI w środowisku produkcyjnym.
