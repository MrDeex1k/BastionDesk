# TLS Certificates

This document describes the local development TLS assets generated for BastionDesk services.

## Source of Truth

The certificates are generated by:

- [`infra/tls/generate-dev-certs.sh`](../../infra/tls/generate-dev-certs.sh)

## Purpose

The script creates a local development certificate authority and service certificates for:

- `backend`
- `llm_service`
- `database`
- `pgbouncer`
- `storage-1`
- `storage-2`
- `storage-3`
- `storage-4`

It also creates a dedicated PgBouncer client certificate for the PostgreSQL superuser defined by `POSTGRES_USER`.

## Output Layout

Generated files are written under:

- `infra/tls/dev/`

Main output directories:

- `infra/tls/dev/ca/`
- `infra/tls/dev/backend/`
- `infra/tls/dev/llm_service/`
- `infra/tls/dev/database/`
- `infra/tls/dev/pgbouncer/`
- `infra/tls/dev/storage-1/`
- `infra/tls/dev/storage-2/`
- `infra/tls/dev/storage-3/`
- `infra/tls/dev/storage-4/`

## Generated Files

### Certificate Authority

- `infra/tls/dev/ca/ca.key`
- `infra/tls/dev/ca/ca.crt`

The CA is reused if it already exists.

### Backend

- `infra/tls/dev/backend/client.crt`
- `infra/tls/dev/backend/client.key`
- `infra/tls/dev/backend/ca.crt`

### LLM Service

- `infra/tls/dev/llm_service/server.crt`
- `infra/tls/dev/llm_service/server.key`
- `infra/tls/dev/llm_service/ca.crt`

### Database

- `infra/tls/dev/database/server.crt`
- `infra/tls/dev/database/server.key`
- `infra/tls/dev/database/ca.crt`

### PgBouncer

- `infra/tls/dev/pgbouncer/server.crt`
- `infra/tls/dev/pgbouncer/server.key`
- `infra/tls/dev/pgbouncer/client.crt`
- `infra/tls/dev/pgbouncer/client.key`
- `infra/tls/dev/pgbouncer/ca.crt`

### MinIO Nodes

For each `storage-N` node:

- `infra/tls/dev/storage-N/public.crt`
- `infra/tls/dev/storage-N/private.key`
- `infra/tls/dev/storage-N/CAs/ca.crt`

## Subject Alternative Names

The generated certificates currently include:

- `backend`: `DNS:backend`, `DNS:localhost`
- `llm_service`: `DNS:llm_service`, `DNS:localhost`
- `database`: `DNS:database`, `DNS:localhost`
- `pgbouncer`: `DNS:pgbouncer`, `DNS:localhost`
- `storage-*`: `DNS:storage-1`, `DNS:storage-2`, `DNS:storage-3`, `DNS:storage-4`, `DNS:localhost`

## Running the Generator

From the repository root:

```sh
sh infra/tls/generate-dev-certs.sh
```

To override the PostgreSQL superuser CN used for the PgBouncer client certificate:

```sh
POSTGRES_USER=my_postgres_user sh infra/tls/generate-dev-certs.sh
```

## Notes

- This script is intended for local development certificates, not for public production PKI.
- Private keys are restricted with `chmod 600`.
- Existing CA files are preserved, so rerunning the script reuses the same local CA unless you remove `infra/tls/dev/ca/`.
