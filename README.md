## Proces uruchomienia

1. Wchodzimy w katalog BastionDesk.  
2. Uruchamiamy komendę "docker compose build" .  
3. Uruchamiamy komendę "docker compose up" lub "docker compose up -d", jeśli chcemy uruchomić w tle.
